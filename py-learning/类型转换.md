## Python 类型转换详解

在 Python 中，**类型转换**（Type Conversion）是指将数据从一种数据类型转换为另一种数据类型的过程。Python 提供了两种转换方式：

- **隐式类型转换**：由解释器自动完成，无需程序员干预。
- **显式类型转换**（也称类型强制转换）：由程序员使用内置函数主动进行。

---

### 1. 隐式类型转换

当不同类型的数据进行运算时，Python 会自动将低精度类型提升为高精度类型，以避免数据丢失。常见规则：

- `int` + `float` → `float`
- `bool` 参与数值运算时，`True` 视为 `1`，`False` 视为 `0`
- `int` 与 `complex` 运算 → `complex`

```python
a = 10      # int
b = 3.14    # float
c = a + b   # 自动转换为 float
print(c, type(c))   # 13.14 <class 'float'>

d = True + 5
print(d, type(d))   # 6 <class 'int'>
```

隐式转换通常发生在数值类型之间，但不会在数值与字符串等非数值类型间自动转换（会报错）。

---

### 2. 显式类型转换

显式转换通过内置函数实现，常用函数如下：

#### 2.1 数值类型转换

| 函数         | 说明                                                         | 示例                                   |
| ------------ | ------------------------------------------------------------ | -------------------------------------- |
| `int(x)`     | 将 `x` 转换为整数。支持数字、布尔、浮点数（截断小数）、纯数字字符串。 | `int(3.9)` → `3`，`int("42")` → `42`   |
| `float(x)`   | 转换为浮点数。                                               | `float(3)` → `3.0`，`float("1.2")` → `1.2` |
| `complex(x)` | 转换为复数（实部+虚部）。                                    | `complex(2, 3)` → `(2+3j)`             |
| `bool(x)`    | 转换为布尔值。常见假值：`None`、`False`、数字0、空容器等。  | `bool([])` → `False`，`bool(42)` → `True` |

> **注意**：`int()` 和 `float()` 转换字符串时，字符串必须表示合法数值，否则抛出 `ValueError`。

#### 2.2 字符串类型转换

| 函数      | 说明                                                         | 示例                                   |
| --------- | ------------------------------------------------------------ | -------------------------------------- |
| `str(x)`  | 将任意对象转换为字符串（调用对象的 `__str__` 方法）。        | `str(123)` → `"123"`                   |
| `repr(x)` | 返回对象的“官方”字符串表示（通常可用于重新创建该对象）。     | `repr("hello")` → `"'hello'"`          |

#### 2.3 容器类型转换

| 函数          | 说明                                                    | 示例                                           |
| ------------- | ------------------------------------------------------- | ---------------------------------------------- |
| `list(iter)`  | 将可迭代对象转换为列表。                                | `list("abc")` → `['a','b','c']`                |
| `tuple(iter)` | 转换为元组。                                            | `tuple([1,2])` → `(1,2)`                       |
| `set(iter)`   | 转换为集合（自动去重）。                                | `set([1,2,2])` → `{1,2}`                       |
| `dict(iter)`  | 将键值对序列转换为字典（例如列表内包含二元元组）。      | `dict([('a',1),('b',2)])` → `{'a':1, 'b':2}`   |
| `frozenset()` | 转换为不可变集合。                                      |                                                |

#### 2.4 其他常用转换

| 函数              | 说明                                                         |
| ----------------- | ------------------------------------------------------------ |
| `bytes(x)`        | 将字符串按指定编码转换为字节串，或创建空字节串。             |
| `bytearray(x)`    | 转换为可变的字节数组。                                       |
| `ord(c)`          | 返回单个字符的 Unicode 码点（整数）。                        |
| `chr(i)`          | 将整数转换为对应的 Unicode 字符。                            |
| `eval(s)`         | 将字符串作为 Python 表达式执行并返回结果（⚠️ 有安全风险，慎用）。 |

### 3. 自定义类的类型转换

在自定义类中，可以通过实现特殊方法（`__int__`、`__float__`、`__str__` 等）来控制该类型对象被显式转换时的行为。

```python
class MyNumber:
    def __init__(self, value):
        self.value = value
    def __int__(self):
        return int(self.value)
    def __str__(self):
        return f"MyNumber({self.value})"

obj = MyNumber(3.14)
print(int(obj))   # 3，调用 __int__
print(str(obj))   # MyNumber(3.14)，调用 __str__
```

### 4. 常见陷阱与注意事项

- **转换错误**：无效转换会抛出异常，建议使用 `try...except` 捕获。
- **精度丢失**：`int()` 截断而非四舍五入；浮点转整数会丢弃小数部分。
- **布尔转换**：非空序列、非零数字等为 `True`，但空容器、`None`、`0` 为 `False`。
- **字符串转列表**：`list("abc")` 得到字符列表，若想拆分成单词需使用 `split()`。
- **eval() 风险**：不要对不可信字符串使用 `eval()`，可使用 `ast.literal_eval()` 安全评估字面量。

### 5. 示例代码集锦

```python
# 数值转换

# 容器转换
s = "hello"

# 字典转换
pairs = [("name", "Alice"), ("age", 25)]
print(dict(pairs))        # {'name': 'Alice', 'age': 25}

# 安全评估字面量
import ast
s = "[1, 2, 3]"
print(ast.literal_eval(s)) # [1, 2, 3]
```

### 1. 基础语法结构

```python
try:
    # 可能抛出异常的代码（业务逻辑）
    result = int(input("请输入数字："))
except:
    # 发生异常时执行的代码（兜底处理）
    print("出错了！")
```

### 2. 捕获特定异常（重要！）

**千万不要用裸的 `except:`**，它会连键盘中断（Ctrl+C）都吃掉，非常危险。应该**明确指定要捕获的异常类型**。

结合类型转换，最常见的异常是：

- **`ValueError`**：值错误（如 `int("abc")`，字符串内容不是数字）
- **`TypeError`**：类型错误（如 `int("3.14")` 虽然字符串是数字，但带小数点会报错，或者 `int([1,2])`）
- **`AttributeError`**：如果转换对象没有对应方法（较少见）

```python
try:
    num = int("abc")  # 这里会抛出 ValueError
except ValueError:
    print("错误：无法将字符串转换为整数，请输入纯数字。")
```

---

### 3. 进阶完整结构：`try-except-else-finally`

```python
try:
    # 1. 试探性执行
    data = input("请输入一个数字：")
    num = int(data)
except ValueError as e:  # 2. 发生异常时执行
    print(f"转换失败，原因：{e}")
    num = 0  # 设置默认值
except TypeError as e:
    print(f"类型不匹配：{e}")
else:
    # 3. 没有发生异常时执行（通常放依赖 try 成功的代码）
    print(f"转换成功！结果是 {num}")
finally:
    # 4. 不管是否发生异常，**一定会执行**（通常放释放资源，如关闭文件、数据库连接）
    print("本次类型转换操作结束。")
```

### 4. 实战：类型转换的健壮封装

在实际开发中，我们通常会封装一个安全的转换函数：

```python
def safe_int(value, default=0):
    """
    安全地将值转换为 int，如果失败则返回默认值
    """
    try:
        # 处理布尔值（bool 是 int 的子类，直接转会有歧义）
        if isinstance(value, bool):
            return int(value)
        # 尝试转换为整数
        return int(value)
    except (ValueError, TypeError):  # 捕获多种异常，可以写在元组里
        return default

# 测试
print(safe_int("123"))      # 123
print(safe_int("12.3"))     # 0（因为 int 不能直接转带小数的字符串）
print(safe_int("abc"))      # 0
print(safe_int(None))       # 0
print(safe_int([1, 2]))     # 0
```

> **补充技巧**：如果你想把 `"12.3"` 转为 `12`，可以先用 `float()` 再转 `int()`，写成 `int(float("12.3"))`，但要注意 `float("abc")` 也会报错，所以同样需要嵌套在 `try` 里。

### 5. 手动抛出异常（`raise`）

在类型转换中，有时我们希望主动中断程序并提示错误：

```python
def validate_age(age_str):
    try:
        age = int(age_str)
    except ValueError:
        raise ValueError("年龄必须是一个整数！")  # 重新抛出更明确的错误
    
    if age < 0:
        raise ValueError("年龄不能为负数！")      # 主动抛出新异常
    return age

# 调用
try:
    validate_age("-5")
except ValueError as e:
    print(e)  # 年龄不能为负数！
```

### 6. 终极技巧：`contextlib.suppress`（忽略异常）

如果你**确定**如果转换失败就保持原样，且不想写 `try...except`，可以使用上下文管理器：

```python
from contextlib import suppress

value = "not_a_number"
with suppress(ValueError, TypeError):
    value = int(value)  # 如果报错，直接跳过这条赋值，value 保持不变

print(value)  # 输出 "not_a_number"
```
不过这种方式**无法获取异常信息**，适合只需要静默失败的场景。

### 7. 总结与最佳实践（针对类型转换）

| 场景 | 推荐做法 |
| :--- | :--- |
| 用户输入转换 | 使用 `try-except ValueError`，捕获后提示重新输入，而不是让程序闪退。 |
| 配置文件 / 环境变量读取 | 使用 `try-except` + 默认值（`default`），保证服务启动不中断。 |
| 列表/字典内的元素提取 | 先 `try` 转，捕获 `(TypeError, ValueError)`，并用 `except` 分支跳过错误数据。 |
| 调试阶段 / 关键逻辑 | 不要捕获异常，让它崩溃，以便快速发现 BUG。上线后再加异常处理。 |
| 捕获范围 | **尽量窄**：只捕获预知的异常（如 `ValueError`），避免写 `except Exception`，更别写 `except:`。 |
