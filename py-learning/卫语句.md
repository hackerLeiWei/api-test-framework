我之前讲过 try-except。卫语句通常使用 if 和 raise（或 return）处理前置条件，代替了用 try 包裹整个逻辑块。

**卫语句**（Guard Clause）是编程中一种**优化代码结构**的技巧，它的核心思想是：**“先处理所有异常情况，尽早返回；主逻辑放在最后，减少嵌套。”**

如果你写过多层嵌套的 `if-else`，一定体会过“箭头型代码”的可读性有多差。卫语句就是用来“拍平”这些嵌套的。

为了让你直观理解，我们先看一段“反面教材”，再对比卫语句的写法。

### 1. 反面教材：深嵌套（箭头代码）
假设我们要写一个给用户发折扣券的函数，条件有三个：用户存在、账户激活、非会员。
```python
def send_discount(user):
    # 这里产生了 3 层嵌套
    if user is not None:
        if user.is_active:
            if not user.is_vip:
                print("发放折扣券")
                # 真正的业务逻辑...
            else:
                print("VIP 不发放")
        else:
            print("账户未激活")
    else:
        print("用户不存在")
```
这种代码逻辑要转好几个弯才能看明白，非常容易出错。

### 2. 正面教材：使用卫语句重构
卫语句的做法是：**一旦发现不满足条件，立即 `return`（或 `raise`），把核心逻辑“拯救”出来。**

```python
def send_discount(user):
    # 卫语句 1：处理空值
    if user is None:
        print("用户不存在")
        return  # 立即返回，不再往下走

    # 卫语句 2：处理未激活
    if not user.is_active:
        print("账户未激活")
        return

    # 卫语句 3：处理 VIP
    if user.is_vip:
        print("VIP 不发放")
        return

    # 核心逻辑（终于回到了第一级缩进，清爽！）
    print("发放折扣券")
    # 假如后面还有 100 行核心业务逻辑，它们都无需再缩进
```

### 3. 卫语句 + raise（配合你的异常处理知识）

既然你之前学了 `try-except`，那么在 Python 中，卫语句经常不写 `return`，而是直接**抛出异常**（`raise`），把错误交给上层调用者统一处理。

```python
def get_user_age(age_str):
    # 卫语句：防御空字符串
    if not age_str:
        raise ValueError("年龄输入不能为空")

    # 卫语句：防御非法字符（利用你学的 int 转换）
    try:
        age = int(age_str)
    except ValueError:
        raise ValueError("年龄必须是数字")  # 这里又用到了 raise

    # 卫语句：防御业务逻辑错误
    if age < 0 or age > 150:
        raise ValueError("年龄超出合理范围")

    # 核心逻辑：只有通过上面所有"守卫"，才执行正常代码
    return age

# 调用时结合 try-except
try:
    age = get_user_age("-5")
except ValueError as e:
    print(f"输入错误：{e}")
```

### 4. 卫语句的实战要点（重点记忆）

| 要点 | 说明 |
| :--- | :--- |
| **优先处理错误** | 把 `None`、空字符串、零、越界等“坏情况”写在最前面。 |
| **减少 `else`** | 使用卫语句后，你会发现代码中 **90% 的 `else` 都可以省略**，因为不合法的情况已经 `return` 或 `raise` 了。 |
| **保持单一职责** | 每个卫语句最好只检查**一个**条件，不要写又长又复杂的 `if` 逻辑。 |
| **与 `try-except` 结合** | 如果卫语句检查发现数据不对，可以用 `raise` 抛出异常，让外层去捕获（这正是你上一问学的）。 |

---

### 5. 特别提醒：卫语句不只是 if

在 Python 中，**`assert`（断言）** 也可以充当卫语句，常用于开发调试阶段：

```python
def divide(a, b):
    assert b != 0, "除数不能为 0"  # 这是一个卫语句检查
    return a / b
```
不过 `assert` 在生产环境可能被优化掉（`-O` 模式），所以处理用户输入等关键业务，**推荐使用 `if + raise`**。

### 总结成一句话

> **卫语句 = 把复杂的「如果 A 且 B 且 C 则执行」倒过来，变成「如果 非A 或 非B 或 非C 则立刻退出」，从而让核心逻辑暴露在最外层，极大地提升代码可读性。**
